# 0005. Next.js 16.4.0 → 16.4.2: патч безпеки в межах мінорної версії 16.4

- Статус: прийнято
- Дата: 2026-10-23
- AC: —

## Контекст

- `npm audit` для production-залежностей показує критичну вразливість у `next` 16.0.0 – 16.4.0; виправлення — 16.4.2. CLI Next.js при кожному першому `dev` і `build` радить `next upgrade --agent=security`.
- `AGENTS.md` забороняє оновлювати стек без ADR: тут змінюється лише патч-версія, мінорна лишається 16.4, але рішення записуємо.

## Рішення

- `next` і `eslint-config-next` піднято з 16.4.0 до 16.4.2 (точні версії, як і було). React 19.3, TypeScript, ESLint, Tailwind не чіпали.
- Окремий PR від `main`, без змін коду застосунку: `package.json` і `package-lock.json` (змінено лише пакети Next; кросплатформні записи lock-файлу збережено).

## Розглянуті варіанти

- **Лишити 16.4.0.** Ні: відома критична вразливість, а оновлення — патч.
- **Піднятися на новішу мінорну.** Ні: стек зафіксований на 16.4; мінорна версія — окремий ADR.
- **Оновити в PR дизайн-системи.** Ні: окремий PR легше відкотити й перевірити.

## Наслідки

- Після злиття CLI більше не показує нагадування про вразливість.
- Перевірено локально: `lint`, `typecheck`, 120 тестів, `build` (`ƒ Proxy (Middleware)`).
