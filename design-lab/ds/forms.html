01 · Overview

Form controls

Every field in Property Workflows, drawn from scratch: no native selects, date inputs, spinners or sliders anywhere. One 32 px shell, one focus ring, one slot for hint and error so validation never shifts the page. Everything on this page is live in both themes — use the mouse or only the keyboard.

32 px shell · 28 / 36 variants Blur, then live validation Kyiv time labelled everywhere Glass only on popovers APG keyboard models

Anatomy

One field, four parts

Principles

  • The label is always above the control and always visible — a placeholder is an example, never the name.
  • Hint, error and note share one grid cell: swapping them is a cross-fade, and a field without a hint grows by a spring instead of jumping.
  • Errors name the problem and the fix. They also carry an icon, so meaning never rides on red alone.
  • Disabled is a muted fill with muted text — never opacity: .5.

02 · Text & textarea

Text field and textarea

Label, hint, counter, leading icon, clear button and error. The counter turns amber at 90% and red over the limit; Esc clears a search field. Textareas grow with their content up to six lines, then scroll.

Keyboard & ARIA

  • Native <input> inside a styled shell: label via for, hint / error / note through aria-describedby, aria-invalid and aria-required.
  • The clear button is a real button with aria-label; it stays hidden, and out of the tab order, until there is text.
  • Error and success text sit in aria-live="polite" regions, so a screen reader hears them when they appear.
  • Clicking anywhere in the shell focuses the input.

03 · Password

Password field

A reveal toggle that keeps focus and selection, and a Caps Lock hint that appears the moment the key is on. The hint is a note, not an error — it never blocks submission.

Keyboard & ARIA

  • Reveal: aria-pressed button, Space / Enter; focus stays in the input and the caret does not move.
  • Caps Lock: getModifierState("CapsLock") on keydown and keyup; the note is aria-live="polite".
  • autocomplete="current-password" and spellcheck="false"; autofill keeps our colours (base.css).

04 · Select & combobox

Select and assignee picker

The select is a button that opens a listbox on a glass popover; the combobox keeps focus in a text field and filters as you type, with highlighted matches, option descriptions, avatars, role tags and a calm “No matches”. The highlight is one element that glides between options.

Select

Listbox · type-ahead · Home / End

Combobox

Assignee picker · async search · aria-activedescendant

Keyboard & ARIA

  • Select: role="combobox" button, aria-haspopup="listbox", ↓ ↑ Enter Space open; type-ahead jumps by prefix; Home End; Esc closes and returns focus; Tab commits.
  • Combobox: text input with aria-autocomplete="list", aria-controls and aria-activedescendant; DOM focus never leaves the input.
  • Result counts, “Searching…” and “No matches” are announced through a polite live region.
  • Disabled options use aria-disabled and are skipped by the arrow keys.

05 · Multi-select

Multi-select with chips

Chips are removable by mouse or Backspace and re-flow with a FLIP, never a jump. The compact variant stays on one line and folds the rest into a “+N” chip that opens the list.

Keyboard & ARIA

  • Same combobox contract as above with aria-multiselectable="true" on the listbox; Enter toggles and the list stays open.
  • Backspace in an empty input removes the last chip; chip buttons carry “Remove …” labels and stay out of the tab order.
  • The “+N” chip names the hidden items in its aria-label.

06 · Date & time

Date, range and time

Fields accept typed text (“24 Oct”, “tomorrow”) and open an ARIA-grid calendar. Everything is labelled “Kyiv time”. “Today” is pinned to Friday 23 Oct 2026 so this page is deterministic. Months cross-slide; the range hover previews the span.

Calendar

ARIA grid · roving tabindex

Keyboard & ARIA

  • Popover is a non-modal role="dialog"; the grid has day headers and one roving tabindex="0" cell.
  • ← → day, ↑ ↓ week, Home End week edges, PgUp PgDn month, Shift+PgUp/PgDn year, Enter picks.
  • Time is two role="spinbutton" segments: ↑ ↓ ±1, PgUp PgDn ±10, digits type through, : jumps to minutes.
  • Past dates are aria-disabled (still reachable, with the reason in the field message).

07 · Number & currency

Number and currency

Euro amounts format as €1,250.00 when idle and become plain editable digits on focus. The stepper accelerates while held: ×2 after 1 s, ×5 after 2 s, ×10 after 3.2 s, with a live rate readout. Min and max disable the matching button.

Keyboard & ARIA

  • role="spinbutton" on a text input (inputmode="decimal"), with aria-valuemin / max / now / text — “€1,250.00”.
  • ↑ ↓ ±step, Shift or PgUp PgDn ±10 steps, Home End to the limits; non-numeric keys are ignored.
  • Steppers are pointer-only helpers (aria-hidden, tabindex="-1"); the keyboard path is the input itself.

08 · Choice & slider

Checkbox, radio, switch, segmented control and slider

The checkbox tick is drawn by stroke-dashoffset, the switch thumb springs, the segmented control’s indicator slides, and slider thumbs grow under the pointer with a value bubble. Boxes are bordered with --border-strong so they pass 3:1.

Segmented control and slider

View switcher · single and range

Keyboard & ARIA

  • Checkbox: real <input>, Space; section parents use the indeterminate state (aria-checked="mixed").
  • Radio group and segmented control: roving tabindex, arrows move and select, Home End.
  • Switch: role="switch", Space / Enter; an async switch shows aria-busy while saving and stays operable.
  • Slider: role="slider", ← → ±step, PgUp PgDn ±10 steps, Home End; aria-valuetext reads “80% confidence”.

09 · File upload

File drop zone

“Choose file” always exists; dropping is an extra. Rejected files stay in the list with the reason — “PDF up to 20 MB.” — instead of vanishing. Try the sample buttons, or drag a real PDF onto the first zone.

Keyboard & ARIA

  • The button is the control (aria-describedby points at the zone text); the file list is an aria-live="polite" region.
  • Progress is role="progressbar" with aria-valuenow; remove buttons say which file they act on.
  • Drag-over adds a state, never a different layout; the dashed border is drawn in SVG so it can animate.

10 · Patterns & launch

Form patterns

Field groups, validation timing and a real form: “Launch a template” — a case name and an assignee picker per task, with a primary button that keeps its width while it works.

Field groups

Fieldset + legend · two-column rows

Validation timing

Stay quiet → on blur → then live

Launch a template

Case name · per-task assignees · loading button

Keyboard & ARIA

  • Required fields get a red asterisk (aria-hidden) and aria-required; optional ones say “Optional”. Never both.
  • Validate when focus leaves a field; once it has been blurred (or is invalid) re-check on every keystroke so the error clears as soon as it is fixed.
  • On submit, focus moves to the first invalid field. The button sets aria-busy and keeps its width; the form is never disabled.
  • Each assignee picker has a visually hidden label naming its task.
