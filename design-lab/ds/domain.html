Domain components

The pieces a property manager looks at all day: a task you tick, a run that fills, an AI draft you accept or reject, an invoice that adds itself up. Every status is an icon plus a word, every number is tabular, and nothing moves without a reason.

01 · Status system

Status, never by color alone

A task is a ring that becomes a drawn check. A run is a ring that fills by N of M. Pills carry a glyph and a word. Only the date turns red when overdue, and “required” stays neutral until someone tries to finish without it.

Lightstates
Darkstates

Anatomy

Task control 16px (14px dense) with a 24px hit target. Run ring 14/16/20px. Pill 20px (18px small): glyph, label, tint. Due date: icon + tabular date; only the date and its icon are tinted.

Keyboard and ARIA

role="checkbox" with aria-checked; a locked task is aria-disabled and stays focusable. Run ring is aria-hidden; the text “2 of 5 done” beside it is the accessible value.

02 · Progress

Rings, bar, and a number that rolls

Tick tasks and everything follows: the ring fills on a smooth spring, the digits roll like a departure board, the bar slides, and finishing the last task flips the run to Completed with one soft glow (≤ 400ms).

Run progress

Click a task, or press Space on a focused one.

Lightring · bar · ticker
Darkring · bar · ticker

Motion

Ring and bar fill on --spring-smooth; digits roll on --spring-snappy. Completed: fill turns green, a disc and check draw in, one --glow-done pulse. Reduced motion: short fades.

Keyboard and ARIA

Ring and bar are decorative (aria-hidden). The accessible value is the sentence “2 of 5 done”, announced politely when it changes.

Tokens

--spring-smooth--spring-snappy--size-bar--duration-celebrate
03 · Checklist

A checklist you can drive from the keyboard

32px rows, Linear-dense. A single selection bar glides between rows. Meta appears only when a task has it. A stop task draws a barrier: nothing beneath it can be ticked until it is done.

Anatomy

Check · index · title · meta (condition, due, assignee, lock) · hover actions. “Next” marks the first open required task. The cursor is one element that slides; rows never change size on hover.

Keyboard and ARIA

role="grid" with aria-activedescendant and one tab stop. J/K or arrows, X or Space toggles. A locked task answers with a message, not silence.

04 · Runs table

Dense 36px rows, overdue first

Sort by any header — rows glide to their new place instead of jumping. Arrow keys move the row cursor, Enter opens. Try the filter, then the loading and empty views.

Sorted by due date, overdue first.

Anatomy

Run name · template · ring + “N of M done” · next task · avatar stack (+N) · due · status pill. Selected row gets a 2px primary edge. Completed runs sort last and drop the due colour.

Keyboard and ARIA

role="grid", roving tabindex, aria-selected on the row, aria-sort on headers. Sort changes are announced in the status line. Sticky header.

05 · Avatars and roles

Initials, not faces

Avatars are initials from the email, tinted from the chart palette so five people stay distinguishable without a photo. Stacks cut each other out with a ring that matches the surface.

Lightavatars
Darkavatars

Anatomy

16 / 20 / 24px. Initial in a tint of the tone, 1px inner edge. Empty assignee: dashed outline with a user glyph. Stack: −4px overlap, hover spreads 3px per item, “+3” pill.

Keyboard and ARIA

Each avatar has role="img" and the full email as its label; a stack is a group labelled with the assignees. Role tag is text (“manager”, “admin”), not colour.

Tokens

--chart-1…5--avatar-ring--size-avatar*
06 · Variables

Type { and pick

Variables are teal chips with a human label; the raw token lives in the tooltip. A run resolves them to values, and an unresolved one says so with a dashed edge instead of failing silently.

Darkchip states

↑↓ move↵ insertesc close

Caret behaviour

A chip is one atomic, non-editable unit: arrows hop over it, Backspace removes it whole, and after insertion the caret lands right behind it so typing carries on. Click selects a chip.

Keyboard and ARIA

Textbox with aria-activedescendant into a listbox; ↑/↓ move, ↵ or Tab insert, Esc closes and keeps what you typed. The menu grows from the caret.

07 · AI draft

Suggested, sourced, never silent

Everything the AI proposes is magenta, marked ✦, tied to a page in the source, and rated High, Check or Low — no fake percentages. You accept or reject each field, or accept the lot; accepted values quietly become normal text.

Lightfield states
Darkfield states

Honest confidence

Three levels, shown as bars and a word: High, Check (look twice), Low (probably wrong). Low is never pre-accepted by “Accept all”.

Keyboard and ARIA

One tab stop; rows are role="listitem" groups with a full spoken summary. ↵ accepts, ⌫ rejects, ⇧↵ accepts all. Results are announced in the status line.

Tokens

--ai*--ai-tint--ai-border--confidence-*--shimmer-duration
08 · Invoice lines

Lines from tasks, totals that add themselves

Each line remembers the task it came from. An AI-suggested line is a draft and stays out of the total until accepted; change a quantity and the totals roll to the new figure.

Anatomy

Item · source task · qty (spinbutton) · unit price · amount, all right-aligned and tabular. Draft line: magenta edge, ✦, tint, inline Accept / Reject. Totals: subtotal, VAT, total (heading weight).

Keyboard and ARIA

Quantity is an aria-valuenow spinbutton: ↑/↓ ±1, PageUp/PageDown ±10. Money is announced as text; the rolling digits are aria-hidden.

09 · Sidebar

Navigation that gets out of the way

240px with counts, collapsing to a 48px rail with tooltips. The collapse is a reveal, not a squash: icons stay put while the edge slides. Press [ anywhere on the page.

Both themes, both widths

Static frames

Anatomy

Workspace switcher + collapse toggle, “Search… ⌘K” entry, nav items (icon, label, count), section headings, footer with user, role tag and menu. Overdue runs add a dot that survives the collapse.

Keyboard and ARIA

nav with aria-current="page"; toggle is aria-expanded; [ toggles. In the rail, hover or focus shows a tooltip with the label and count.

Tokens

--sidebar*--size-sidebar--size-sidebar-collapsed--spring-smooth
10 · Run page

Three zones, one thread

Checklist on the left, the selected task in the middle, run variables and documents on the right. Compact preview: select a task, complete it, and accept an AI-read value — the run header keeps up.

Composition

300 / fluid / 272px. Zones separate with hairlines; the checklist sits one tone darker (--sidebar) like a rail. Under 1100px the right zone drops; under 860px zones stack.

Keyboard and ARIA

Zones are landmarks (region) with labels. Checklist behaves as in §03; the detail pane follows the selection and keeps focus where the user is.

Tokens

--sidebar--surface-1--radius-lg--size-header
