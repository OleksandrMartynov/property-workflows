# Logos

Знак **Echo Roof**: два вкладені контури даху з однаковим штрихом на одній базовій лінії й суцільні «двері»; зовнішні контури — пройдені етапи, двері — поточний крок. Читається і як дім, і як запуск, що просувається етапами.

Файли тут — для `<img>`, а там `currentColor` не успадковується, тож знак пофарбований чорнилом світлої теми. У коді беріть інлайн-варіант із `currentColor` (компонент `Logo`, див. Logo у каталозі) і фарбуйте його токеном.

- `pw-mark.svg` — знак на сітці 24, чорнило `#445dad` (`primary`, світла тема). У коді: `currentColor` з `primary`, `foreground` або `sidebar-foreground`.
- `pw-mark-20.svg` — сітка 20 для сайдбару; чорнило `#445dad`.
- `pw-mark-16.svg` — піксельно вирівняна сітка 16 для фавікона й таб-бару; чорнило `#445dad`. Не стискайте сітку 24 до 16: краї розмиваються.
- `pw-lockup.svg` — знак (`#445dad`, `primary`) і напис «Property Workflows» Inter 600, трекінг −0.03em, чорнило напису `#1a1814` (`foreground`, світла тема). Напис — текст, не контури: у застосунку збирайте лок-ап розміткою.
- `pw-app-icon.svg` — плитка `primary` 512×512, радіус 115 (22.5%), знак 56% кольору `#f8fafe` (`primary-foreground`).
- `pw-favicon.svg` — сітка 16; `#445dad` у світлій системній темі й `#8aa8f7` (`primary`, dark) у темній — через `prefers-color-scheme` усередині SVG.

Правила: вільне поле — подвійна ширина дверей; мінімум 16px для знака й 96px для лок-апа; лише одне чорнило; ніколи `ai`-магента, градієнти, тіні чи обведення; не обертати й не розтягувати.
