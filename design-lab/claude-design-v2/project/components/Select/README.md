# Select

Родина вибору зі списку без системного списку: Select (один варіант), Combobox (вибір із пошуком, типово виконавець), MultiSelect (кілька варіантів фішками). Спільна основа — скляний listbox на `Popover` і рядки з `listbox-parts.tsx`. Джерело — `select.tsx`, `combobox.tsx`, `multi-select.tsx`, `listbox-parts.tsx`, `popover.tsx`, `select-family.css`.

## Токени й вигляд

- Поле як Input: межа `input`, заливка `field`, висота `size-control` (32px), hover — `border-hover` (на крок темніша за `input`), focus — межа `ring` і outline `ring-width` усередину (`-1px`), invalid — межа `destructive` і значок оклику, disabled — заливка `muted`, межа `border`.
- Список — `.surface-float`: скло `glass-bg` (`popover` на `glass-alpha` 84%, blur 20px), межа `border`, `radius-md`, `elevation-3`; паддинг 4px; висота до `size-listbox-max` (16.5rem), далі прокрутка. Не клади скло на скло.
- Рядок — `size-option` (2rem), із описом чи аватаром — `size-option-rich` (2.75rem); радіус `radius-xs`, підпис `label` 13/18. Активний рядок — заливка `accent-float` (ковзна підсвітка: один елемент їде між рядками на `spring-snappy`), вибраний — галочка `primary` праворуч, вимкнений — `muted-foreground`.
- Збіг пошуку — `<mark>` із заливкою `match`. Група — підпис `meta` вагою 500 у `muted-foreground`, між групами hairline `border`.
- Порожній результат — іконка пошуку, жирне «No matches», без пояснень; завантаження — скелет рядків (`skeleton`) і спінер у полі.

## Select

Кнопка-комбобокс (ARIA select-only combobox), шеврон розвертається на пружині. Варіанти — `<option>` / `<optgroup>` у дітях або `options={[…]}` з `description`, `leading`, `trailing`, `group`, `disabled`. Пошук над списком вмикається автоматично, коли варіантів більше 8 (`searchable`): фокус переходить у рядок пошуку, ↑ ↓ і Enter працюють звідти. Порожнє значення показується приглушеним як placeholder («Assign all to…»). Значення йде у форму через прихований input, тож server actions читають його як звичайний select.

- Клавіатура: ↑ ↓ Home End, Enter або Пропуск вибирають, Esc закриває й повертає фокус на кнопку, набір літер переходить до варіанта (у довгому списку відкриває пошук із цим символом), Tab закриває.
- Список відкривається під полем, перевертається вгору, коли знизу тісно; клік поза ним закриває.

## Combobox

Поле з автодоповненням (ARIA 1.2 combobox, `aria-autocomplete="list"`, `aria-activedescendant`): фокус лишається в полі. Вільного тексту немає: Esc або вихід з поля повертають підпис вибраного. Вибраний варіант показує аватар 20px; рядок списку — аватар 24px, ім'я, email під ним (`description`), `RoleBadge` (щит або людина + слово) і галочку. Кнопка «очистити» (`aria-label="Clear"`) з'являється, коли поле заповнене; Esc очищає. Enter у полі ніколи не відправляє форму. Живий регіон `aria-live` озвучує кількість результатів.

## MultiSelect

Вибрані значення — фішки висотою `size-chip` у самому полі, решта поля — фільтр. Фішка: `secondary` із hairline, текст `meta` вагою 500, кнопка «✕» `aria-label="Remove …"`, для людей — аватар 18px і ім'я без домену. Видалення мишею, «✕» або Backspace при порожньому фільтрі; решта фішок переїжджає на нове місце пружиною (FLIP). Рядки списку мають чекбокс `size-check` (галочка домальовується), список лишається відкритим. `compact` тримає поле в одну лінію: фішки, що не вмістилися, згортаються в «+N» (`control-off`). У форму йде окремий прихований input на кожне значення.

## Стани

default · hover · focus · open (`aria-expanded`) · filled · invalid (`aria-invalid`, значок, текст помилки під полем із `role="alert"`) · disabled · loading (`aria-busy`, спінер).

## Do / Don't

- Do: підпис завжди видно (`Label`); для виконавців — Combobox із аватаром, іменем, email і роллю; помилка дослівно з AC.
- Don't: нативний `<select>` у сторінках; пояснення під полем «про всяк випадок»; скло на склі; колір ролі без слова.
