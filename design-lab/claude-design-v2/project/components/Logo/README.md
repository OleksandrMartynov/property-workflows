# Logo

Знак Echo Roof — дах, що луною повторює себе всередині: «один процес, який щоразу запускається знову»; Logo — знак у кольорі `primary` плюс назва продукту. Джерело — `logo.tsx`, файли — група «Logos».

## Частини

- `LogoMark` — SVG 24×24: два вкладені контури даху (штрих 2) і суцільні «двері». Колір — `currentColor`; розмір за замовчуванням 20px; без `title` — `aria-hidden`, із `title` — `role="img"`.
- `Logo` — знак у `primary` (20px) і «Property Workflows» у стилі `heading` (15/20, вага 600, трекінг −0.025em), проміжок 8px, текст `foreground`. `showName={false}` лишає знак.

## Правила

- Чорнило лише одне: `primary`, `foreground`, `sidebar-foreground`; на плитці `primary` — `primary-foreground`. Ніколи `ai`, градієнти, тіні, обведення; не обертати й не розтягувати.
- Сітки: 24 — основна, 20 — сайдбар, 16 — піксельно вирівняна для фавікона й таб-бару. Не стискайте 24 до 16: краї розмиваються.
- Вільне поле — не менше за подвійну ширину дверей; мінімум 16px для знака й 96px для лок-апа.
- Лок-ап у файлі (`pw-lockup.svg`) тримає напис текстом, а не контурами: у застосунку збирайте його розміткою.
- Файли: `pw-mark.svg`, `pw-mark-20.svg`, `pw-mark-16.svg`, `pw-lockup.svg`, `pw-app-icon.svg` (плитка `primary`, радіус 22.5%, знак 56%), `pw-favicon.svg` (світла й темна тема всередині SVG).

## Рух

Лише на вході й завантаженні, один раз: двері 0–360ms, внутрішній контур 140–700ms, зовнішній 280–920ms. При reduced motion — статичний знак.

## Do / Don't

- Do: знак поруч із назвою в сайдбарі й на вході; фавікон із сітки 16.
- Don't: знак в кольорі статусу; новий знак «для свята»; назва без знака в сайдбарі.
