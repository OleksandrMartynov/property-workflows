# EmptyState

Порожній список: що тут буде (одне речення з AC) і одна дія, що робити далі. Без пояснень «про всяк випадок». Джерело — `empty-state.tsx`.

## Вигляд

Пунктирна межа (`border-strong` 50%, `radius-md`), паддинг 48px × 24px, вміст по центру з проміжком 12px. Угорі — лінійна іконка дому 40px у `muted-foreground` 60%: суцільний контур і пунктирний «відлуній» (та сама ідея, що в лого). Заголовок — `heading` (15/20); опису немає (правило мінімуму тексту).

## Що дає споживач

- `title` — що тут буде: «No runs yet.» Текст дослівно з AC, якщо він там є.
- `action` — одна кнопка (`default`) або посилання з `buttonVariants`: «Launch a template». Кнопка називає дію, не «OK».

## Do / Don't

- Do: одна дія; пояснення без вибачень; той самий стан для «немає даних» і «фільтр без результатів» — з іншим текстом.
- Don't: підзаголовок під заголовком; дві кнопки рівної ваги; ілюстрації з людьми й емодзі; помилку завантаження показувати як порожній список (для помилки — `Alert`).
